# SetiIpress

Proyecto de Microsoft Access para el registro y consolidación de información de salud.

## Contenido

- `database/`: archivos Access de desarrollo y distribución.
- `assets/`: logotipos e imágenes utilizadas por el sistema.
- `docs/`: documentación funcional.

## Reglas de seguridad

- Este repositorio debe mantenerse **privado**.
- No agregar archivos `.laccdb` ni `.ldb`.
- No publicar exportaciones con datos reales de pacientes fuera de este repositorio privado.
- Antes de distribuir a usuarios, generar una versión `.accde` de 32 o 64 bits según corresponda.

## Desarrollo

Los formularios principales incluyen Configuración, Tablas A, E, F, H, I y J, acumulación de datos y control de usuarios por nivel.
